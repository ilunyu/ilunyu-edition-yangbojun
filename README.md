# 杨伯峻《论语译注》资源

本仓库保存《论语》阅读与学习系统所使用的杨伯峻《论语译注》结构化资源，包括原文、译文与注释。

## 版本依据

目前内容以**中华书局 2019 年 1 月北京第 1 版**《论语译注（简体字本）》为依据整理。

后续如发现不同印次或版本之间存在文字、标点、断句、译文或注释差异，原则上以**较新的版本**为准；若新版有明确勘误、增订或改排，也应在修订时优先采用新版内容。

## 安装与使用

本仓库应作为主项目的独立资源仓库克隆到以下位置：

```bash
git clone git@github.com:9LucasCT/ilunyu-edition-yangbojun.git \
  res/editions/yangbojun
```

在主项目根目录运行内容构建脚本：

```bash
python3 tools/build_flutter_content.py
```

脚本会读取本目录的源文件，生成 Flutter Web 运行时使用的标准化内容到：

```text
flutter_app/assets/content/editions/yangbojun.json
```

随后可构建 Web 前端：

```bash
cd flutter_app
flutter build web
```

构建脚本只读取本仓库内容，不会改写本目录中的源 JSON。

## 目录与数据格式

```text
.
├── metadata.json          # 书名、作者、出版社与版本信息
├── 01-xueer.json          # 学而篇第一
├── 02-weizheng.json       # 为政篇第二
├── ...
└── 20-yaoyue.json         # 尧曰篇第二十
```

每个篇文件包含该篇的标题、说明和 `content` 章节数组。章节的常用字段如下：

```jsonc
{
  "id": "0101",                  // 稳定章 ID
  "text": "子[1]曰……",           // 原文；[n] 指向第 n 条注释
  "translate": "……",             // 译文，可为空
  "annotation": [
    {"label": "子", "text": "……"}
  ]
}
```

### 注释标记规则

- 原文 `text` 中的 `[n]` 表示链接到 `annotation` 数组中第 `n` 条注释。
- 标记编号必须位于 `1` 到 `annotation.length` 的范围内。
- 同一条注释可以在原文中被多次引用，例如同一个 `[1]` 出现多次；因此标记**出现次数**不必与 `annotation` 数组长度相等。
- 不显示注释的纯文本场景会自动移除 `[n]` 标记。

## 内容勘误与修改建议

欢迎通过本仓库的 **GitHub Issue** 提出内容修改意见，包括但不限于：

- 错字、漏字、异体字；
- 标点、断句或引号问题；
- 原文、译文、注释的遗漏或误录；
- 注释索引位置、编号或格式问题；
- 章节标题、篇章归属等结构问题。

为便于核对，请在 Issue 中尽量提供：

1. 篇名、章号或章节 `id`；
2. 原文中的具体位置，以及当前内容与建议内容；
3. 所依据书籍的完整版本信息，至少包括出版社、出版时间或印次；
4. **对应书页的清晰图片**，应能看清页码及相关文字；
5. 如适用，补充其他可靠参考来源与说明。

我们会优先依据较新的正式版本核校；若所提供版本早于现行依据，请同时说明其差异的来源或理由。也欢迎以 Pull Request 提交已经按本仓库格式整理好的修订，但一般内容勘误建议建议先通过 Issue 讨论。
